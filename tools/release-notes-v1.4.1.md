## 📱 Instalacja / Install

**Pobierz APK bezpośrednio z repozytorium:**
➡️ [release/VisionPocket-v1.4.1.apk](https://github.com/rejson59/VisionPocket/raw/arena/49b8c2a9-visionpocket/release/VisionPocket-v1.4.1.apk) *(kliknij prawym przyciskiem → „Zapisz link jako..." / right-click → "Save link as...")*

Android 8.0+ (API 26+). Przed instalacją zezwól na „nieznane aplikacje".

*(Binary upload to GitHub Releases assets is blocked in the build environment — the APK lives in the repo under `release/` on this branch.)*

## 🆕 Co nowego / What's new (v1.4.1)

- 🩺 **Okno Diagnostyka** — model, GPU, sensory, uprawnienia, FPS (Ustawienia → 🩺) — idealne do zgłaszania problemów
- 🧠 **Sesja przywraca też ostatni film** w kinie po restarcie aplikacji
- 🔊 **Przyciski głośności** sterują kinem (poza nim — głośność systemowa)
- 🔄 **Auto-wyśrodkowanie przy starcie** (przełącznik w Środowisku)
- ☀️ **Jasność passthrough** 0.5–1.5× (Środowisko → −/+)

## Pełna lista funkcji / Full feature set

MR passthrough (przód/tył), 3 środowiska, panoramy 360° (zdjęcie/wideo, 3 tryby projekcji), system okien w przestrzeni z chwytem/bezwładnością/głębią/skalowaniem, curved kino + SBS 3D, duplikat ekranu (MediaProjection), launcher aplikacji, klawiatura 3D, notatki, wizualizator muzyki, gamepad BT z laserem, adaptacyjna rozdzielczość, sesja pulpitu, kalibracja IPD, zrzuty VR, PL/EN — wszystko w APK ~270 KB.

## 🧪 Test w 10 minut / Quick test

1. START VR → passthrough → stuknij ikony w docku
2. Chwyć okno palcem → dwa palce = głębia/skalowanie
3. 🎬 → 📂 → film → curved screen → tap = pauza
4. ▣ → Start mirroring → otwórz YouTube na telefonie
5. Ustawienia → 🩺 Diagnostyka → zrób zrzut, jeśli coś nie działa
