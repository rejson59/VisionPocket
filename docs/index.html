Telefon podłączony przez ADB?

Przeglądarka nie może sama użyć ADB (bezpieczeństwo USB/Chrome) — ale z komputera, przy podłączonym telefonie, cała instalacja to jedna linijka w terminalu:

curl -L -o vp.apk "https://rejson59.github.io/VisionPocket/VisionPocket-v3.4.apk?v=34" && adb install -r vp.apk
Wymaga: debugowanie USB włączone na telefonie (Ustawienia → Opcje programisty → Debugowanie USB) i sprawdzonego adb devices. Flaga -r aktualizuje istniejącą instalację bez utraty ustawień i notatek.
Windows PowerShell: curl.exe zamiast curl (albo pobierz APK przyciskiem powyżej i przeciągnij plik na telefon).
Lokalnie z komputera, bez pobierania (jeśli masz repo): adb install -r release/VisionPocket-v3.4.apk

Coś nie działa?

W aplikacji: ⚙ Ustawienia → 🩺 Diagnostyka → 📤 Wyślij raport — raport zawiera model, GPU, FPS, sensory i konfigurację montażu. Wyślij go wszędzie tam, gdzie zgłaszasz problem.

Najczęstsze tematy: obraz krzywo? → 🔄 w Ustawieniach (×1–×3) · podwójny obraz? → kalibracja IPD · wygięty przez soczewki? → Zniekształcenie 20–60%.
